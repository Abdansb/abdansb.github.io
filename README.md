# Abdan's Blog 🚀

Welcome to the source code of my personal blog. This site is built using **Jekyll** with the **Chirpy** theme and hosted on **GitHub Pages**.

Here, I write about my journey in tech, specifically focusing on:
* 🐧 **Linux:** Arch Linux, Puppy Linux, and Window Managers.
* 💻 **Programming:** C, Python, and Shell Scripting.
* ⚡ **Electronics:** Hardware mods and microcontrollers.

## 🛠️ Tech Stack

* **Generator:** [Jekyll](https://jekyllrb.com/)
* **Theme:** [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy)
* **Deployment:** GitHub Actions
* **Comments:** Giscus (GitHub Discussions)
* **Analytics:** GoatCounter
